# Deployment input

`dist/public/` is the only directory intended to become the Nginx web root. It is generated by `npm run build`; do not deploy the repository root.

The build has an explicit entry allowlist. It copies public HTML, the two current admin shells, required local frontend assets, and navbar/footer templates. It never copies server code, SQL, JSON dumps, `.env`, logs, binaries, planning files, Git metadata, `docs/`, or the bulk `projects/` archive.

Admin HTML is present so the application can function, but it is not public content: noindex/auth rules remain work for task 06B and Nginx access controls, if approved, belong to task 04. The directory does not replace RLS.

Run from the repository root:

```powershell
npm run build
```

The machine that deploys must use the resulting `dist/public/`. `dist/build-manifest.json` is a local verification report and is outside the web root.
